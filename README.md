# Rock Paper Scissors

A console-based Rock Paper Scissors game built in vanilla JavaScript, as part of [The Odin Project](https://www.theodinproject.com/) curriculum.

## How to Play

1. Clone the repo and open `index.html` in your browser
2. Open the DevTools console
3. The game runs automatically — respond to the prompts to play 5 rounds against the computer

## Features

- Random computer choice (rock/paper/scissors)
- Case-insensitive human input (`Rock`, `rock`, `ROCK` all work)
- Input validation with reprompting on invalid entries
- Round-by-round score tracking and result logging
- Final winner announced after 5 rounds

## What I Learned

- Using `Math.random()` and `Math.floor()` to generate random selections
- Scope and closures — nesting functions to access variables without relying on global state
- Writing case-insensitive string comparisons
- Using `while` loops for input validation (reprompt until valid)

## Tech

- HTML
- Vanilla JavaScript (no frameworks)
